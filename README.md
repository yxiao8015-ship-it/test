## 🎮 小游戏集合 / Mini Games Collection

这是一个包含多个有趣的小游戏的项目！

## 📂 游戏列表 / Games List

### 1. 🔢 数字猜谜游戏 (Number Guessing Game)
**文件**: `number_game.py`

一个简单而上瘾的猜数字游戏，有三个难度等级。

**特性**:
- 🎯 三个难度等级：简单（1-10）、普通（1-100）、困难（1-1000）
- 💡 实时反馈：告诉你猜测的数字是太高还是太低
- 🎯 限制尝试次数：根据难度不同，有不同的尝试次数
- 🔁 可重复游玩

**如何运行**:
```bash
python number_game.py
```

**操作方法**:
1. 选择难度等级（1-3）
2. 输入你的数字猜测
3. 根据提示调整你的猜测
4. 猜对后选择是否继续游玩

### 2. ✋ 石头剪刀布游戏 (Rock Paper Scissors Game)
**文件**: `rock_paper_scissors.py`

经典的玩家 vs 电脑游戏！

**特性**:
- 🤖 与电脑对战
- 📊 实时记分系统
- 🎯 完整的游戏规则
- 🔁 可以连续游玩多轮

**如何运行**:
```bash
python rock_paper_scissors.py
```

**操作方法**:
1. 选择你的出招（1=石头、2=剪刀、3=布）
2. 查看电脑的选择
3. 查看当前分数
4. 输入 4 退出游戏

---

### 3. 🃏 21点纸牌游戏 (Blackjack Game)
**文件**: `blackjack.py`

经典的赌博卡牌游戏！目标是获得接近21点但不超过21点的手牌。

**特性**:
- 💰 虚拟筹码系统（初始 $100）
- 🃏 真实的21点游戏规则
- 🤖 智能的庄家AI
- 📊 Ace 牌的智能处理
- 🎯 完整的游戏流程

**如何运行**:
```bash
python blackjack.py
```

**操作方法**:
1. 输入下注金额
2. 选择"要牌"（1）或"停牌"（2）
3. 系统会自动播放庄家的回合
4. 查看最终结果和获胜金额
5. 继续游玩或退出

**21点规则**:
- 目标：手牌总值接近21但不超过21
- 数字牌：面值对应的数字
- 图片牌（J、Q、K）：10点
- Ace：可以是11或1（自动调整）
- 庄家在17点或更高时停牌

### 4. ⭕ 井字棋游戏 (Tic Tac Toe Game)
**文件**: `tictactoe.py`

与聪明的电脑对手玩井字棋！

**特性**:
- 🤖 智能AI对手
- 🎯 多种策略：
  - 尝试赢得游戏
  - 防守对手的必胜着法
  - 优先选择中心位置
  - 选择角落位置
- 📋 清晰的棋盘显示
- 🔁 可重复游玩

**如何运行**:
```bash
python tictactoe.py
```

**操作方法**:
1. 查看棋盘位置编号（0-8）
2. 输入你想放置棋子的位置
3. 电脑会自动做出回应
4. 继续直到出现赢家或平手
5. 选择是否再玩一局

**棋盘位置**:
```
0 | 1 | 2
---------
3 | 4 | 5
---------
6 | 7 | 8
```

## 🚀 快速开始 / Quick Start

### 系统要求
- Python 3.6+
- 无需额外依赖（所有游戏仅使用Python标准库）

### 运行任意游戏
```bash
# 例如：运行数字猜谜游戏
python number_game.py

# 或者：运行21点游戏
python blackjack.py
```

### 在菜单中选择游戏
如果你想创建一个主菜单来选择游戏，可以创建 `main_menu.py`：

```bash
python main_menu.py
```
